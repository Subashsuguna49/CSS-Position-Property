# CSS Position Property

This practice covers the **CSS Position property** and how it controls the placement of elements on a webpage.

## 📌 Topics Covered

* `position: static`
* `position: relative`
* `position: absolute`
* `position: fixed`
* `position: sticky`
* `top`, `right`, `bottom`, `left`
* `z-index`

## 🎯 What I Learned

* How different position values work
* How to position elements relative to their parent
* How to fix elements to the viewport
* How to create sticky elements
* How `z-index` controls element stacking
