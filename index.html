Css Position property

  1. position:static => no movement

  2. position:relative => Move from its normal position

  3. position:absolute => Position relative to a positioned parent

  4. position:fixed => fixed position is if we scroll the page its act like Stays on the screen

  5. position:sticky => Sticks while scrolling and we can set the position
